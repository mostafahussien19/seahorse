# Acme Billing: Domain Context

Invoices, payments and refunds for small shops. An Express API in server/ and a React app in web/, backed by Postgres.

Generated by Seahorse onboarding on 2026-10-22 from the discovery proposal. Edit freely: agents read this file.

## Stack
- Node 20
- Express 4
- Postgres 15
- React 18
- Vite

## Modules
| Path | What lives there | Owner |
|------|------------------|-------|
| `server/` | REST API, payment provider webhooks, background jobs | api_agent |
| `web/` | React app for shop owners: invoices, payments, settings | web_agent |
| `db/migrations/` | SQL migrations | api_agent |

## Conventions
- ESM everywhere, with .js extensions in imports (server/src/app.js)
- Money is stored and passed as integer cents, never floats (server/src/money.js)
- Every data-fetching component handles loading, error and empty states (web/src/components/InvoiceList.jsx)

## Constraints
- **Every database query is scoped by accountId from the session, never from the request body** (`server/src/db/scope.js`)
- **Payment provider webhooks are verified by signature before any state changes** (`server/src/webhooks/verify.js`)
